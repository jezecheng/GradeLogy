# Planning documents

This folder contains implementation plans and their completion records.

## Status convention

- `analysis`: current code and behavior are being verified.
- `planned`: scope, dependencies, and acceptance checks are ready for implementation.
- `in progress`: implementation or validation is underway.
- `completed`: all accepted items have implementation evidence, tests, documentation updates, and any required migration checks.
- `deferred` / `out of scope`: record the reason and any follow-up decision.

Do not mark a plan completed merely because code changes are present. Update the plan with per-item status and evidence when work is finished.
