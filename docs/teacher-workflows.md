# 教师流程与前置条件

本页是教师端业务流程的**当前事实表**，用于核对开始一项操作前必须具备什么、完成后应进入哪一步。数字助手和 MCP 的 `ask_help` 优先检索本页；回答时必须区分硬性条件、推荐项、自动流程专属条件和可选功能。以当前代码、服务端权限校验及回归测试为准。

## 先确认账号、角色和课程范围

| 事项 | 前置条件与边界 |
|---|---|
| 登录 | 使用已启用账号。管理员创建老师和学生账号；初始密码登录后先改密。 |
| 学生出现在课程中 | 学生账号已创建、启用，并由老师加入课程；学生只能查看已加入课程的讲次并提交自己的作业。老师代上传也必须选本课程已加入的学生。 |
| 老师操作课程 | 必须是老师账号。课程创建者及共同管理老师有相应权限；创建者独有课程信息编辑、管理共同老师和删除课程等权限。 |
| 当前部署的权限开关 | `TEMPORARY_GLOBAL_TEACHER_ACCESS` 默认是 `1`：暂时允许所有老师访问任意课程，并获得所有图谱的编辑权限；设为 `0` 后才按课程成员及图谱协作权限限制。页面助手和 MCP 教师工具都使用此模式。部署前应按数据隔离要求明确设置。 |
| 外部 MCP 身份 | `mcp_server.py` 仅接受一个 `GRADELOGY_TEACHER` 老师账号；同一 MCP 进程的所有调用共用该账号，不会识别 WorkBuddy/其他客户端里的各个用户。 |

## 手动 AI 批阅前置条件

开始手动批阅前必须有：**一份学生提交、教师版标准答案 PDF、基于当前答案成功生成的题目清单、至少一个已勾选并保存的作业范围题目**。正常模式还需当前老师的 API 地址、Key、模型配置完整可用，模型支持图片输入；开启「仅闲时批阅」时，高峰期不能启动。演示模式可生成占位结果，不会请求真实 AI。**知识点标签与知识图谱都不是手动批阅条件。**

批阅发送的是学生提交的完整页面与教师版已选页；未选教师版页等同整份答案。更换教师版答案、页码或范围后，旧题目清单/批阅依据失效，须重新准备。

## 自动 AI 批阅前置条件

除满足手动批阅的数据准备外，自动批阅还要求**当前保存的作业范围已成功生成知识点标签**、非演示模式、AI 配置完整可用、未被「仅闲时批阅」拦截，并且提交次数未超过上限。每位学生每讲默认只有前 3 次提交可自动批阅；超出后老师仍可手动批阅。

新提交、保存作业范围、标签生成成功时都会尝试立即入队；定时扫描默认每 6 小时运行，`AUTO_GRADE=0` 只关闭定时扫描，不关闭事件触发。共享课程的自动批阅使用课程创建者的 AI 配置和次数上限；手动批阅使用当前操作老师的配置。

## 报告生成与发布前置条件

**生成报告**：至少有一道批阅题、批阅任务已结束，且全部题目已人工复核或老师明确跳过复核。正常模式还需完整可用的 AI 配置以生成评价；未配置或模型调用失败时，本次报告任务可能失败。演示模式不调用 AI，可生成结构性报告。

**发布报告**：上述复核/跳过条件满足，报告已成功生成，且没有仍在运行的批阅任务；然后在报告页点击「一键发布给学生」。人工复核完成和报告生成都不会自动公开。此单一发布状态同时控制报告、逐题结果、错题本与薄弱点的学生可见性。

## 主流程：从课程到学生看到批改结果

1. **建课和名单**：老师创建课程；管理员先创建并启用学生账号，老师再把学生加入课程。未加入名单的学生看不到讲次，也不能提交。
2. **建讲次、准备文件**：在课程内建讲次。教师版标准答案 PDF 是批阅依据，必须上传；学生版讲义只用于学生预览，可选，不能替代标准答案。
3. **生成题目清单并保存作业范围**：在「作业范围」选教师版答案页，点击「保存并生成题目列表」，等待成功，再勾选至少一个实际布置的独立批改项并保存。未选答案页表示使用整份答案。仅保存范围不会调用 AI。
4. **收作业**：学生提交图片/PDF，或老师为已加入本课程的学生代上传。提交保存在待批阅状态；若自动批阅条件齐全，可能立即入队，否则仍需老师手动批阅。
5. **AI 批阅**：老师可手动开始批阅；硬性业务条件是教师版答案、成功生成的题目清单、至少一个已保存的范围题目和一份提交。知识点标签**不是手动批阅的前置条件**。正常 AI 模式还需完整可用的 AI 地址、Key、模型和可读取图片的多模态模型；演示模式会生成占位结果，不调用真实 AI。开启「仅闲时批阅」时，高峰期会被拦截。
6. **人工复核或明确跳过**：批阅结果生成后，逐题检查 OCR、标准答案、判定和评语，并将每题标记为已复核。所有题目完成后才可走人工复核路径生成报告。也可明确选择「跳过人工复核并生成报告」；此路径要求已有批阅结果、无正在运行的批阅任务且尚无报告，报告会标明未人工复核。
7. **生成报告并检查**：需至少有一道批阅结果、批阅任务已结束，并且全部题目已复核或已明确跳过复核。正常模式下报告还需要可用 AI 配置来生成评价；未配置/调用失败时本次报告任务可能失败，旧报告不会被不完整结果覆盖。演示模式不调用 AI，可生成结构性报告。
8. **发布**：在报告页确认报告已生成后点击「一键发布给学生」。报告、逐题结果、错题本和薄弱点均以同一个发布状态控制；复核完成或生成报告本身都不会自动公开。撤回发布会一起隐藏这些结果。

### 每个动作的依赖速查

| 动作 | 必须先完成 | 不属于前置条件 / 结果 |
|---|---|---|
| 学生提交 | 学生账号启用且已加入课程；讲次存在 | 学生版讲义不是提交前置条件；教师版答案也不是“上传提交”前置条件，但缺答案时不能批阅。 |
| 手动 AI 批阅 | 学生提交；教师版答案；题目清单成功生成；至少勾选并保存一道题；AI 模式下配置可用的 API 地址、Key、模型 | 标签不要求已生成。正常模型必须支持图片输入；学生作业页面会整份发送，答案只发送已选页（未选页即整份）。 |
| 自动 AI 批阅 | 满足手动批阅的数据准备；当前已保存范围的标签生成成功；完整 AI 配置可用且非演示模式；未被闲时规则拦截；提交未超过自动批阅次数上限 | 标签是自动批阅专属条件，不是手动批阅条件。默认每个学生每讲仅前 3 次提交自动批阅，之后需老师手动触发。定时扫描默认每 6 小时；上传、保存范围或标签生成成功时也会尝试立即入队。`AUTO_GRADE=0` 关闭定时扫描，但不关闭这些事件触发的尝试。共享课程的自动批阅使用课程创建者的 AI 配置和次数上限；手动批阅使用当前操作老师的配置。 |
| 生成/重生成标签 | 已上传教师版答案；题目清单已生成且至少一个范围题目已保存；AI 配置可用；非演示模式且未被闲时规则拦截 | 可在批阅前生成；范围保存不会自动生成标签。生成失败不清除已保存范围，可重试。标签用于自动批阅门槛、错题/薄弱点及知识点分析。 |
| 横向知识点分析 | 本讲有知识点标签；有已批阅逐题判定数据；AI 可用且未被闲时规则拦截 | 生成的是异步 AI 分析。页面上的 `错 + 半对 / 已判定记录数` 是数据库统计，不是 AI 分析。 |
| 纵向知识点分析 | 当前课程内该学生有可分析的跨讲次批阅/标签数据；AI 可用且未被闲时规则拦截 | 课程图谱关联可帮助前置关系诊断，但不是生成分析的普遍必需项；诊断需教师判断。 |
| 报告发布 | 至少有一道批阅题；每题已复核或明确跳过；报告已成功生成；批阅任务不在排队/运行 | 只有报告页的发布开关公开结果；学生只看到自己的已发布结果。 |

## 改答案、页码或题目范围：会让旧结果失效

- 替换教师版答案会清空答案页选择、题目清单和已选范围；必须重新选页、生成清单、选择并保存范围。
- 更改答案页或重新生成题目清单后，也必须重新选择范围。没有保存有效范围时不能批阅。
- 若本讲已有批阅、报告、标签或分析，系统会先要求确认；确认后清除本讲派生的逐题批阅/报告/复核标记、标签、题目难度与分析，撤回发布，并按其他仍发布的讲次重算薄弱点。**学生原始提交文件保留**。
- 有批阅、报告或相关分析任务仍在运行时，必须等任务结束后才能重设范围或替换答案，避免旧任务写回。
- 修改前应先核对影响提示；不能把确认页面当成普通保存提示。

## 讲次编号、正确率与成绩含义

- 题目清单按识别顺序编号。母题有小问时，母题用于承载公共题干和分组；独立批改项为 `1.1`、`1.2` 等，母题本身不另算一道题。可只选部分小问，也可勾母题一次选中全部小问。
- 作业按题目判定，不单独录入总分。正确率 = 判为「对」的独立批改项数 ÷ 独立批改项总数；「半对」不计完全答对，「无法判定」仍计入分母。
- 考试与讲次作业分开。考试只录入分数/评语或明确标为缺考，不走 AI 批阅；保存已录成绩后学生可见。零分是有效成绩，缺考不等于零分，待录入也不等于缺考。

## 图谱与分析的依赖边界

- 知识图谱关联是可选项，不影响建课、提交、手动/自动批阅、复核或报告生成。
- 所有教师可浏览系统图谱并关联到自己可访问的课程；正常权限模式下，图谱编辑/管理和原始资料下载还要符合图谱协作角色。临时全局教师访问模式开启时，老师被赋予图谱编辑权限，见本页权限开关说明。
- 标签不依赖图谱即可生成和用于统计；图谱主要用于标签与概念匹配及前置关系诊断。扫描版知识图谱 PDF 若没有可抽取文字层，不能按当前文本抽取流程建图。
- 只有 `report_published=1` 的讲次结果进入学生错题本和薄弱点；没有标签的题无法按知识点进入薄弱点统计。知识图谱匹配不到时，标签仍可单独显示，但不会点亮对应图谱节点。

## MCP / 数字助手回答操作问题的规则

- 问“怎么做”或“开始前需要什么”时，先调用 `ask_help`，依据本页和当前角色正式手册回答；不要仅根据工具中的实时数据推断操作条件。
- 回答顺序：**必须条件 → 可选/推荐项 → 按钮顺序 → 完成后的状态/下一步**。明确区分手动批阅和自动批阅、标签和图谱的作用、复核完成和已发布。
- 遇到「批阅」「报告」「发布」「作业范围」「知识点标签」等问题时，引用本页相应依赖速查。资料没有写明的条件不要补猜；课程或讲次不明确时先问名称。
- MCP 的数据工具只读。`mcp_server.py` 固定使用一个 `GRADELOGY_TEACHER` 身份；全局访问开关默认开启时，该老师工具能读取全平台课程数据。部署者应了解这会把学生成绩等敏感数据暴露给该 MCP 客户端，并通过设置 `TEMPORARY_GLOBAL_TEACHER_ACCESS=0` 关闭临时全局课程访问。
