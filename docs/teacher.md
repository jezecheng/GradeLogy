# 老师手册

老师负责课程、学生名单、讲次与批改，以及考试成绩录入。所有功能都在登录后的导航栏入口。

结构是「课程 → 讲次 / 考试」：一个课程下可以有若干讲次（每次作业即一讲）和若干场考试。

| 层级 | 是什么 | 能做什么 |
|------|--------|----------|
| 讲次 | 一次作业 / 一讲内容 | 上传教师版标准答案、收学生提交、AI 批阅与人工复核 |
| 考试 | 一张卷 | 只录入分数与评语，不上传试卷、不做 AI 批阅 |

## 登录与改密

- 账号由管理员创建；初始密码为 `123456` 时，首次登录必须先改密
- 右上角姓名可进入改密页

## 课程与学生名单

### 创建课程

「我的课程」→ 填写课程名称与简介 → 创建。课程卡片显示学生数、讲次数与考试数。创建者进入课程页后可点「编辑课程」修改课程名称与简介。

### 添加学生

进入课程页，在「学生名单」卡片里从下拉中选择学生 → 「加入课程」。

- 下拉只列出管理员已创建、**处于启用状态**且尚未加入本课程的学生账号
- 建号由管理员负责；老师端不建号，也不再提供课程内的 CSV 批量导入

### 移出学生

名单每一行最右侧是「移出」按钮，点击后需在弹窗里二次确认。

⚠️ 移出是**数据库层面的永久删除**：该学生在本课程内的全部讲次提交、逐题批改结果、考试成绩与选课关系都会被删除，无法恢复。学生的账号与其它课程的数据不受影响。若只是想让其不再登录，请让管理员「停用」账号。

### 多名老师共同管理同一课程

课程页顶部「共同管理老师」卡片展示本课程的所有老师：

- **创建者**：建课的人，可以编辑课程名称与简介、添加 / 移除其它老师，也只有他能删除课程
- **共同管理**：可进入课程、管理学生名单、建改讲次与考试、批阅与发布报告，但不能编辑课程信息或增删老师
- 添加方式：点「＋ 添加老师」，从老师账号下拉中选择（只列出尚未加入本课程的老师）
- 移除后对方账号与其它课程不受影响；「我的课程」列表会显示「N 位老师共同管理」

## 讲次与标准答案

### 新建讲次

课程页「讲次」卡片：填写标题（如「01_绪论」，讲次按标题升序排列）、说明、截止时间，可同时上传**学生版讲义 PDF**（发给学生的原卷，学生端可预览）与**教师版标准答案 PDF**（AI 批阅时作参考），两份都可稍后补传。一个课程可以有任意多个讲次。

### 编辑讲次

讲次页底部「讲次信息」可改标题、说明与截止时间，保存即生效；清空截止时间再保存即取消截止限制。课程页讲次表格里会显示该讲有无「学生版 / 教师版」文件。

### 上传 / 更换答案

讲次页「标准答案（教师版）」卡片支持上传或更换答案 PDF；上方「学生版讲义」卡片用于上传发给学生的原卷。AI 批改以教师版 PDF 为参考。

### 代学生上传作业

讲次页「提交与批阅」卡片右上角「代学生上传」：选择学生后，可一次选择多张图片 / PDF，或在手机上直接拍照。文件先进入**草稿箱**，可预览缩略图、逐个删除，点「确认上传」才真正写入。

- 同一批多图记为**一次提交**，列表显示 `查看扫描件 1/3`、`2/3`，AI 批阅会按顺序合并
- 单文件 ≤20MB，一次最多 20 个文件
- 需要更正时直接再传一次即可，**以最新一次提交为准**

### 设置作业范围（只批改布置的题目）

上传教师版标准答案后即可使用「作业范围」卡片。AI 批阅本身也依赖教师版答案，因此标准流程是先上传答案、再划定范围：

1. 点「分析标准答案生成题目列表」，AI 读一遍教师版 PDF，列出题号、满分与考查内容（约 20~60 秒）
2. 勾选本讲实际布置的题目（可「全选 / 全不选」），保存
3. 之后每份作业的 AI 批阅只处理勾选的题目，未勾选的题目不会出现在批阅结果里

必须至少勾选一道题并保存，AI 批阅才会执行；没有教师版答案或没有划定范围时，即使学生已经提交作业，批阅按钮也不可用。换答案时点「重新分析标准答案」即可刷新清单。

### 教师版页码（只发送相关页，省 token）

「作业范围」卡片里还有一块「教师版页码」：系统把教师版 PDF 逐页渲染成缩略图，勾选本讲作业实际对应的页。

- 学生交的是 PDF 的第几页，这里就勾第几页；批阅时只把这些页发给模型
- 支持按打印习惯填范围：`1-5, 8, 10-12`，点「按范围勾选」自动对应缩略图
- 也提供「全选 / 全不选」；**全不选并保存 = 发送整份答案**
- 保存后的页码同时用于「生成题目清单」和「AI 批阅」；未保存页码或全不选时分析、批阅整份答案
- 更换教师版 PDF 会自动清空已选页码（页数可能变了），需要重新勾选

按一份 26 页学生卷 + 20 页答案算，答案只勾 4 页可把发给模型的图片从 46 张降到 30 张，输入 token 减少约三成。

### 查看单个学生的进度

课程页学生名单里点姓名（或「进度」）进入学生详情：上方是该生在本课程每一讲次的提交次数、状态与正确率（可直达批阅页），下方是该生所有考试的得分与评语。学生资料（姓名 / 学籍号）与登录密码由管理员统一维护，老师端只读。

### 批阅方式（整份原卷，不切题）

讲次页不需要「提取标准答案」；但必须先上传教师版答案并划定作业范围，未上传答案或未划定范围时批阅不会执行。点提交卡片上的「AI 批阅」时，系统会把两份材料一起交给模型：

1. 学生提交的作业（PDF 或扫描图片）
2. 作业的教师版标准答案 PDF

系统把两份文件的每一页渲染成图片后一次性发送，模型看到完整原卷，逐题输出题号、学生作答 OCR、标准答案要点、判定、建议分数与评语，不做任何题目裁剪。需要「AI 设置」里选择**支持图片输入**的多模态模型，输出上限建议 ≥32k。

单份批阅实测：约 26 页图片、45 题，DeepSeek 视觉版约 90 秒、4.5 万 token；模型卡死时 5 分钟超时后直接报错，不会反复重试。

## AI 设置

导航栏「AI 设置」：

| 项 | 说明 |
|----|------|
| 接口地址 | 任意 OpenAI 兼容服务，如 `https://tokenhub.tencentmaas.com/v1` |
| API Key | 留空提交表示保持原值不变 |
| 模型 | 必须是**支持图片输入的多模态模型**，如 `deepseek-v4.1-flash`（腾讯云 TokenHub 推荐）、`glm-5.3-flash`、`gpt-4o` |
| 演示模式 | 未配 Key 时可用，生成占位批阅结果，仅用于走通流程 |
| 测试连接 | 发送一次最小请求验证地址、Key 与模型 |

服务端若通过环境变量注入了 `AI_API_URL / AI_API_KEY / AI_MODEL`，会优先于页面配置。

## AI 消耗记录

讲次详情、逐题核对和教师版批改报告页面底部会显示「AI 消耗记录」，用于查看作业范围分析、作业批阅、讲次汇总、自动生成报告评价和重新生成总评的消耗。

- 每次点击都会生成一条新的操作记录；重新分析、重新批阅和重新生成不会覆盖旧记录，失败的操作也会保留
- 每次记录展示输入、输出、合计 token、整体耗时和预估费用；发生自动重试时，各次请求分别保存，页面展示合计值与请求次数
- token 来自服务商返回的 `usage`，数据库同时保存可获得的缓存 token 与推理 token；服务商未返回时显示「未知」，不会按 0 计算
- 费用按操作开始时的模型输入价、输出价和高峰倍率快照估算，仅供成本参考，实际费用以服务商账单为准；缺少 token 或模型价格时费用显示「未知」
- 演示模式不产生真实消耗记录；仅在本地重排报告、没有调用 AI 时也不记录。数字助手和「测试连接」暂未纳入此记录

## 我的提示词

导航栏「我的提示词」管理 AI 批改与报告生成所用的提示词：

- 系统内置「默认批改提示词」「默认报告提示词」，全局可用、不可删除、不可修改；
  代码升级时内容会自动更新。
- 点「复制为我的提示词」得到可自由修改的副本，改到满意后在课程页选用。
- 自建提示词可命名、修改、复制多份做对比测试、删除；删除后引用它的课程自动回落到系统默认。
- 只需写规则与要求，JSON 输出格式由系统自动追加，保证批改结果能被解析。

课程页「提示词配置」为本课程分别选择批改提示词与报告提示词；不选即用系统默认。
共同管理该课程的其他老师自建的提示词也会出现在下拉里。

## AI 批改与人工复核

### 开始批改

讲次页的提交列表，每份提交有两个入口：

- **AI 批阅 / 重新批阅**：把学生作业与标准答案整份交给模型，一次返回逐题结果
- **逐题核对**：打开发布前的复核页

### 复核页

两栏同屏：

| 左 | 右 |
|----|----|
| 可编辑的 OCR 文本框、判定、评语 | 该题标准答案（可修正） |

- 每题有判定下拉：对 / 半对 / 错 / 无法判定；可修改评语
- 作业不单独赋分，页面底部按判定统计正确率（完全答对题数 ÷ 已判定题数）
- 点击保存后，提交状态变为「已批改」，学生端立即可见；**保存即发布**
- 页面右上角「查看原始扫描件」可并排打开学生原卷 PDF 核对

### 快速手动更正

逐题核对页保存后即为最终结果，总分与评语在该页统一修改。

## 批改报告

AI 批阅完成后会自动生成一份 Markdown 批改报告（逐题明细表、失分点归因、评价），可在讲次页「批改报告」进入查看。

复核与发布的顺序：

1. 打开「逐题核对」页，题目默认全部折叠，折叠时标题栏就显示「待复核 / ✓ 已复核」
2. 逐题点开核对，改完点「标记已复核」；右上角显示「已复核 x/N 题」
3. 全部复核完成后，「总评」下方的「生成新的总评」才可用；点它会按本次逐题结果让 AI 重写总评并回填到文本框，可继续手工修改
4. 全部题目都「已复核」后，「生成批阅报告」按钮才可点击；未复核完时按钮呈禁用样式，点击会弹窗提示还需审核多少题
5. 点「生成批阅报告」保存当前结果并跳到报告页；报告页的「编辑报告内容（Markdown）」可直接改源文并保存
6. 确认无误后点「发布给学生」，学生在「我的学习 → 讲次」里能看到逐题明细与报告；点「撤回发布」即收回

其他说明：

- 报告默认是草稿，学生看不到；逐题明细同样要等老师保存复核结果或发布报告后才公开
- 逐题核对保存时会按最新结果刷新报告表格与统计，评价段落沿用上次生成的内容
- 「重新生成」会重新调用模型写评价；「下载 .md」可导出源文件
- 报告包含：每个学生的逐题判定（✅/⚠️/❌）、统计行、失分点归因表，以及「做得好的地方 / 需要改的几处 / 下一步建议」

## 课程备份

课程页「课程备份」卡片点「导出课程备份」，会把整个课程打包成 zip 直接下载。只有本课程的老师（创建者与共同管理老师）能导出，其他老师与学生无权访问。

压缩包按「课程 → 讲次 → 学生」整理：

```text
课程名/
  讲次名/
    教案-学生版.pdf
    教案-教师版.pdf
    学生用户名/
      批改报告.md
      提交作业/
        原始作业文件.pdf
```

- 教案取讲次页上传的学生版讲义与教师版答案；未上传的一侧不会出现在包内
- 每个学生一个文件夹，使用登录用户名；多次提交会合并到「提交作业」，重名文件自动加序号
- 批改报告取该生最新一次已生成的报告；尚未批阅的学生不会生成报告文件
- 同名讲次会自动追加序号（如「第1讲 极限 (2)」）避免互相覆盖
- 生成后直接下载，同时服务器保留 1 天，期间可在卡片下方再次下载；过期自动清理

## 考试与成绩录入

课程页「考试」卡片可新建考试（名称、日期、满分、说明）；考试只记分数，不上传试卷、不走 AI 批阅。

点考试进入录分页：按学生逐个填写分数与评语，留空表示未参加或未录入。保存后学生端「考试成绩」立即可见；把分数清空再保存即撤回该学生的成绩。

## 教案

课程页「教案」卡片：新建、编辑、删除。教案内容为纯文本，按课程归属。

## 数字助手

老师页面右下角的圆形按钮可以打开「教学助手」，它只读查询你自己的数据，不会修改任何内容。

能回答三类问题：

- **怎么操作**：如「作业范围怎么设」「报告怎么发布给学生」，回答来自本手册原文
- **作业情况**：如「这次作业交了几份、哪道题错得最多」→ 汇总提交数、批改数、每题对/半对/错分布
- **学生评价**：如「张三这次作业怎么样」→ 逐题判定、评语、总分与批改报告

使用时注意：

- 只查得到你自己参与的课程；换老师账号登录看到的范围不同
- 对话保留在当前标签页，关掉标签页或点「新对话」即清空；切换页面不会丢
- 每次提问调用一次模型（约 2~6 秒），开销很小，不受「仅闲时批阅」限制
- 回答由模型根据查询结果组织，数字来自数据库；若有疑问，以页面上的实际数据为准

### 在外部 AI 客户端里使用（MCP）

仓库根目录的 `mcp_server.py` 是一个只读 MCP 服务器，可挂到 Trae、Claude Desktop、Cursor 等支持 MCP 的客户端：

```json
{
  "mcpServers": {
    "gradelogy": {
      "command": "/绝对路径/.venv/bin/python",
      "args": ["/绝对路径/mcp_server.py"],
      "env": { "GRADELOGY_TEACHER": "teacher1" }
    }
  }
}
```

- 工具与页面助手完全相同：`ask_help`、`list_courses`、`list_lectures`、`lecture_status`、`find_student`、`student_report`
- 只对老师账号开放：`GRADELOGY_TEACHER` 填的不是老师账号时，进程直接退出
- 只读，不含任何写操作；数据库路径默认取 `DATA_DIR/data.sqlite`，可用 `DB_PATH` 覆盖

## 常见问题

| 现象 | 处理 |
|------|------|
| 批改全部失败 | 检查 AI 设置与额度；日志中看 `HTTP 402` / `429` / `请求失败` |
| 提示模型不支持图片 | 换用支持图片输入的多模态模型；纯文本模型无法读取扫描件 |
| 批阅超时（5 分钟） | 模型卡住或题量过大；换更快的视觉模型，或压缩 PDF 页数后重试 |
| 输出被截断 | 模型输出上限太小或题量过多；调大输出上限或减少一次批阅的页数 |
| 题目漏判 | 模型未返回的题不会凭空补；可在复核页手动补充，或重试批阅 |
| 批改很慢 | 整份 PDF 一次请求，页数越多越慢；可压缩 PDF 后重试 |
| 学生看不到成绩 | 确认已保存复核页（状态应为「已批改」） |
