# 老师手册

老师负责课程、学生名单、作业与批改。所有功能都在登录后的导航栏入口。

## 登录与改密

- 账号由管理员创建；初始密码为 `123456` 时，首次登录必须先改密
- 右上角姓名可进入改密页

## 课程与学生名单

### 创建课程

「我的课程」→ 填写课程名称与简介 → 创建。课程卡片显示学生数与作业数。

### 添加学生

进入课程页，两种方式：

1. **单个加入**：从「学生账号」下拉中选择（列表只显示管理员已创建、且尚未加入本课程的学生）
2. **CSV 批量导入**：展开「批量导入学生名单（CSV）」，上传后先进入预览页，确认后才写入

CSV 格式（每行一条，首行表头可选）：

```
用户名,姓名,初始密码
stu001,张三
stu002,李四,abc123
```

导入规则：

- 上传后先预览：逐行列出「新建账号 / 加入课程 / 已在课程 / 无法处理」，**确认前不会写库**
- 用户名已存在 → 直接加入课程，不重复建号
- 用户名不存在 → 自动创建学生账号并加入课程
- 未填密码时使用 `123456`，该账号首次登录强制改密；填写自定义密码则不强制
- 校验用户名（2-32 位字母、数字或 `_.-`）、密码长度（≥6）、文件内重复、同名非学生账号
- 支持 UTF-8（含 Excel 的 BOM）与 GBK；Excel 请另存为「CSV UTF-8」
- 单次最多 1000 行、文件 ≤1MB；错误行在预览页完整列出，确认后汇总提示
- 预览内容暂存 1 小时，超时需重新上传

移出学生不会删除账号，只解除该课程的选课关系。

### 批量建课并导入学生

「我的课程」→ 展开「批量建课并导入学生（CSV）」，每行「课程,用户名,姓名[,初始密码]」：

```
课程,用户名,姓名
高二（1）班,stu001,张三
高二（1）班,stu002,李四
高二（2）班,stu003,王五,abc123
```

- 课程按名称匹配：当前老师名下不存在则自动创建，已存在则复用
- 学生规则与单个课程导入相同；同一文件内可一次创建多门课程
- 同样先预览（汇总新课程数、学生动作），确认后才写库
- 单次最多 2000 行、文件 ≤1MB；预览暂存 1 小时

## 作业与标准答案

### 发布作业

课程页「作业」卡片：填写标题、说明、截止时间，可同时上传教师版标准答案 PDF（也可稍后上传）。

### 上传 / 更换答案

作业详情页「标准答案」卡片支持上传或更换答案 PDF。AI 批改以该 PDF 为参考。

### 提取标准答案（建议先做）

作业详情页点击「提取标准答案」：

- 系统对教师版 PDF 做一次「切题 + 裁题图 + 提取答案文本」，缓存进数据库
- 题目图按 `<课程>/<作业>/answer/` 归档
- 之后所有学生的批改直接复用缓存，不再重复解析 PDF
- 更换 PDF 后点「重新提取」覆盖

### 绑定批改流程

作业详情页「批改流程」下拉：默认流程为「按页切题 → 定位答案 → 逐题判分」，也可选择设计器中保存的自定义流程。

## AI 设置

导航栏「AI 设置」：

| 项 | 说明 |
|----|------|
| 接口地址 | 任意 OpenAI 兼容服务，如 `https://tokenhub.tencentmaas.com/v1` |
| API Key | 留空提交表示保持原值不变 |
| 模型 | 必须是**视觉模型**，如 `hunyuan-t1-vision-20250916` |
| 演示模式 | 未配 Key 时可用，按页等分生成占位题目，仅用于走通流程 |
| 测试连接 | 发送一次最小请求验证地址、Key 与模型 |

服务端若通过环境变量注入了 `AI_API_URL / AI_API_KEY / AI_MODEL`，会优先于页面配置。

## AI 批改与人工复核

### 开始批改

作业详情页的提交列表，每份提交有两个入口：

- **AI 识别切分**：走完整流水线（切题 → 定位答案 → 逐题判分），题量越多耗时越长
- **逐题批改**：打开三栏复核页

### 复核页

三栏同屏：

| 左 | 中 | 右 |
|----|----|----|
| 题目裁剪图 | 可编辑的 OCR 文本框 | 该题标准答案 |

- 每题有判定下拉：对 / 半对 / 错 / 无法判定；可修改得分与评语
- 页面底部填写总分与总评
- 点击保存后，提交状态变为「已批改」，学生端立即可见；**保存即发布**
- 修正判定后，错题本会同步更新（「对」不再计入，「半对 / 错」计入）

### 快速手动更正

提交卡片里的「手动更正批改」可直接改总分与总评，不改逐题记录，同样会把状态置为「已批改」。

## 错题本

导航栏「错题本」：

- 首页按课程汇总：错题数、涉及学生数
- 课程页可按学生筛选、按状态筛选（全部 / 待复习 / 已掌握）
- 每条错题展示学生、作业、题号、判定、得分、评语、作答裁剪图，可展开 OCR 与标准答案，也可跳回原批改页
- 操作：「复习 +1」「标记已掌握」「恢复待复习」；已掌握的条目半透明显示
- 只统计已发布（已批改）的提交，草稿不会出现

## 教案

课程页「教案」卡片：新建、编辑、删除。教案内容为纯文本，按课程归属。

## 附件

导航栏「附件」浏览 `uploads/attachments/` 目录树，可查看文件与删除。

> 删除被批改记录引用的图片会导致批改页缺图；不确定时先用「系统维护 → 一致性检查」查看影响面（管理员权限）。

## 批改流程设计器

导航栏「批改流程」：

1. 左侧面板列出 `utilities/manifest.json` 注册的节点（detect / match / grade 等）
2. 拖入画布、连线、点选节点编辑参数
3. 保存为命名流程，在作业详情页绑定

默认流程不需要设计器，直接在作业页使用即可。

## 常见问题

| 现象 | 处理 |
|------|------|
| 批改全部失败 | 检查 AI 设置与额度；日志中看 `HTTP 402` / `429` / `请求失败` |
| 模型返回空 | 思考型模型 `max_tokens` 太小会被推理耗尽，调大到 6000 以上 |
| 切题漏页 | detect 已按单页处理；仍漏时可换提示词或模型，见 README 路线图 |
| 题号对不上答案 | 教师版与学生版题号体系可能不一致；建议使用同一版讲义，或先「提取标准答案」再核对 |
| 批改很慢 | 当前逐题串行，44 题约 15-20 分钟；可减少页数或等待并发优化 |
| 学生看不到成绩 | 确认已保存复核页（状态应为「已批改」） |
