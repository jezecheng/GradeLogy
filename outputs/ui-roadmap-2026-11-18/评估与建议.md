# 教师端 UI 与 roadmap 评估

日期：2026-11-18；代码基准：`b8a1fd6`。本次检查实际模板、样式、交互、路由和相关业务代码，并用独立数据库导入用户提供的化学图谱。所有班级、学生与作业均为模拟数据，未调用真实 AI。

## 结论

最值得先做的是按教师任务重排信息：先找到待处理的讲次或学生，再批阅、复核、发布；协作、提示词、模型配置与费用明细放入明确的设置入口。已有移动端样式和折叠控件可以保留，进一步改善任务顺序、状态表达和空间分配。

建议先完成共同布局和课程/讲次，再做批阅工作区，之后优化图谱浏览、提示词和 AI 设置。图谱版本与任务可靠性应先于自动治理；学生复习闭环应先于全自动生成补救路径。

## 页面编排建议

浏览器实测使用本机 Chrome，在 1440×1000、1920×1080 和 390×844 三种视口检查 8 个教师页面，共 24 次页面检查：均为 HTTP 200，没有捕获到 JavaScript 页面异常或整页横向溢出，三种尺寸的星图均成功加载。未做真实手机或低性能设备验证，也没有验证全部表单提交。

| 具体证据（模拟数据） | 影响 |
| --- | --- |
| 30 人班级的课程页：讲次标题在桌面 y=2,619px，手机 y=3,154px | 高频入口被配置和名单挤到页面下方，应改顺序和分区 |
| 仅图谱样本无资料：星图标题在桌面 y=1,077px，手机 y=1,648px | 上传表单与成环告警占据首屏；浏览和治理应分区，告警保留可见摘要 |
| 1920px 宽屏内容区仍为 1240px；AI 配置卡片最大宽度 520px | 普通文字页可以保持限宽，批阅、图与配置比较需要专用宽度 |
| 1440px 打开原卷时，主区域约 738px，右侧 PDF 约 662px | 固定 46vw 会压缩内部两列；应可调宽或按剩余空间改变模式 |
| 手机小按钮常见 30–32px 高，图谱面包屑按钮约 19px 高 | 无整页溢出仍不等于容易点击，应扩大命中区域 |
| 手机复核截图中助手悬浮按钮覆盖右下方审核操作 | 工作区隐藏首次引导或改为工具栏入口，避免覆盖固定操作 |

截图：[手机课程首屏](course-mobile.png)、[手机单题复核](review-expanded-mobile.png)、[桌面图谱](graph-canvas-desktop.png)。布局建议可在 [交互草案](布局草案.html) 中切换桌面/手机及五个示例页面；草案不会写入应用。

样本检测出 **5 组成环前置子图**。例如算法建议优先核查“半衰期 → 速率常数”，该边模型置信度仍达 95%；这只是环中低置信边的检查建议，不证明它应被删除。应由教师确认边方向和语义，也说明高自评分不能直接作为自动治理依据。

| 页面 | 当前情况 | 建议顺序与操作 |
| --- | --- | --- |
| 全局导航 | 多个链接、账号、帮助和任务放在同一条导航；手机通过换行容纳 | 桌面稳定侧栏或紧凑顶部导航，显示当前位置；手机保留课程、图谱、任务和更多，提示词/设置从更多进入 |
| 我的课程 | 创建表单始终在课程列表前，课程卡直接显示删除 | 标题旁“新建课程”，已有课程优先；空状态再展开创建。卡片显示待批阅/待复核数量；删除移入更多菜单 |
| 课程详情 | 共同老师→提示词→图谱→学生→讲次→备份→考试，日常工作靠后 | 概览与待办在顶部；页签为讲次、学生、考试、课程设置。协作、提示词、关联图谱和备份归入设置 |
| 讲次详情 | 信息、讲义、标准答案和作业范围在提交列表前 | 标题与准备状态→提交/批阅列表→教学分析。上传答案、范围设置在未完成时突出，完成后收为摘要 |
| 批阅复核 | AI 汇总位于题目之前，所有题默认折叠；保存文案仍暗示总会公开 | 进入第一个未复核题，顶部显示进度；提供全部/待复核/无法判定筛选。主动作按状态显示“保存草稿”或“完成复核并公开逐题结果”，报告公开单独表达 |
| 知识图谱 | 资料管理、星图、概念表和治理卡片纵向堆叠 | 浏览、资料、治理、协作分区；默认浏览。搜索、分类导航、图和概念详情组成同一工作区。上传/失败任务摘要可跨分区提醒 |
| 我的提示词 | 四类分区纵向排列；自己的每条提示词默认展开完整编辑器 | 类型筛选+搜索→提示词列表→单条编辑；显示被哪些课程使用。默认模板只读，“复制后编辑”优先；校验占位符并明确测试是否会调用 AI |
| AI 设置 | 多张 520px 窄卡片；连接、模型表、输出上限、价目更新混排 | 当前有效连接与模型→连接管理→常用批阅设置；高级输出上限、价目和演示模式默认折叠。手机每套连接用摘要卡，编辑时展开 |

“横向”适用于相互比较的对象，如 OCR 与标准答案、图与概念详情、多个状态统计。“纵向”适用于有先后关系的步骤，如上传答案→选择范围→批阅→复核→公开。不把整个教学流程排成一条过宽的按钮带。

## 屏幕适配规则

以下是下一版的起始设计规则，需要结合真实内容验收，而非仅按设备名称切换：

| 宽度 | 普通页面 | 批阅与图谱工作区 |
| --- | --- | --- |
| 小于 768px | 单列，12–16px 留白，紧凑导航；重要摘要常驻 | 单题工作区；作答/标准答案切换，原页独立查看。图谱优先搜索与分类，图可进入专注浏览；详情用底部抽屉 |
| 768–1199px | 根据内容保留一至两列，设置页采用一个主列 | 可切换对照双列；原页覆盖查看时保留编辑状态；图详情可收起，避免强行三列 |
| 1200–1599px | 内容区约 1200–1320px，表单仍约 640–760px | 批阅采用题目导航+对照编辑，原页按需显示；图占主要宽度，详情侧栏 |
| 1600px 以上 | 列表适量扩展，不拉长所有文字段落 | 工作区可扩展到约 1800px；原页与编辑区域可调宽，避免固定 46vw 直接挤压双列文字 |

手机交互目标至少 44×44px，紧密图表用更大的透明命中区域；表单文字保持至少 16px，避免 iOS 输入放大。宽表保留局部横向滚动，但姓名、状态和主要操作必须在默认视野内。长公式可局部滚动，整页不得横向溢出。

底部固定操作区应留出安全区和内容占位；出现软键盘时不得挡住输入与保存。横屏、浏览器缩放至 200%、键盘操作和减少动画设置也应纳入验收。手机浏览器模拟不能替代真实 iPhone Safari 与 Android 验证。

## 折叠规则

| 内容 | 默认状态 | 自动展开条件 |
| --- | --- | --- |
| 当前未复核题 | 展开一题；保留题号和状态列表 | 下一题、筛选命中、定位错误 |
| 已复核题和 AI 长总评 | 折叠，有摘要 | 教师主动查看 |
| 上传答案/作业范围 | 完成后折叠，显示文件和选题摘要 | 未配置、失败或教师点击修改 |
| 协作、提示词、课程图谱关联 | 在课程设置内 | 教师进入设置，或首次必要配置 |
| 图谱概念详情 | 未选节点时收起 | 点击或键盘选择概念 |
| 治理建议 | 摘要可见，内容按记录折叠 | 待确认/失败；正常历史不自动展开 |
| AI 明细、存储和价目表 | 折叠，保留总量和异常摘要 | 查看详情或发生失败 |

保留用户在当前课程或工作区的展开选择；轮询、窗口变化和任务完成不能突然展开长区块或改变滚动位置。切到另一个账号时不能沿用前一个账号的工作状态。

## Roadmap 实现核对

采用“已实现 / 部分实现 / 未发现实现 / 已调整范围”，不以测试数估算功能完成百分比。

| 文档目标 | 当前进展与代码依据 | 建议下一步 |
| --- | --- | --- |
| P1 根因联动 | 部分实现。`_kg_diagnosis`、相关讲次/横纵分析上下文已把标签匹配到前置关系，报告和学生薄弱点可查看；未发现教师确认/否决诊断与持久复习计划 | 优先支持教师修正映射，展示命中依据、未匹配和未考查项 |
| P2 质量治理自动化 | 部分实现。已有体检、分类、预览、应用和安全回滚；尚无置信度校准、定时体检和经过教学验证的自动应用 | 先做修订版本及应用时重校验，再做建议分组与证据展示；模型自评分不能直接成为自动合并阈值 |
| P3 教学闭环 | 部分实现。错题本、薄弱点合并、复习状态与前置知识展示已有；已有分析中的文字复习建议；未发现可执行且可跟踪的复习路径或班级/讲次覆盖热力图 | 先做教师确认的小范围复习清单，再记录练习与复测，之后评价干预效果 |
| P4 工程能力 | 部分实现。资料增量合并、文本块续建、JSON ZIP 迁移、分类分层与局部表格/邻域接口已有；多进程队列、资料版本重建、GraphML 和完整差异历史未实现 | 任务持久化、输入版本与取消机制优先；再补资料新版本及完整迁移。GraphML 可后置 |
| P5 治理与审计 | 部分实现。访问/登录/AI 日志及体检/分类记录已有；全量变更审计、快照保留策略、图谱归档和跨学科概念对齐不足 | 建立统一变更记录、操作者、输入版本、影响范围与保留规则 |
| 分批批阅 | 未发现实现。`grade_pdf_submission` 仍将整份学生卷和答案整页交给模型；出现“部分批次”文案不代表分组调度已完成 | 先用长卷样本测量上限，建立稳定题目键、漏题检测与重叠页处理；保留原卷，不依赖切题 |
| 模型成本实测 | 部分实现。已有 usage、价格快照与估算；未建立可重现的多模型图片折算及教师复核质量基准 | 固定匿名样本，比较完整率、教师修正量、延迟和每份总费用，含重试与推理 token |
| Excel 导出 | 未发现实现。课程 ZIP 包和 Markdown 报告下载已有，不能等同于成绩 Excel 导出 | 可作为较小的交付项；先明确分数/正确率含义、复核状态及授权范围 |
| 管理员批量建号 | 已实现，CSV 导入在管理员端。README 中“学生名单 CSV 导入（已移除）”容易误读 | 改为管理员统一批量建号及课程名单维护，避免同时写完成与移除 |
| 备份恢复和一致性检查 | 基础已实现；会话失效已修复，但并发排空和数据库/文件整体故障回退未完成 | 区分“功能可用”与“在线恢复具备事务级可靠性” |
| 系统解耦 | 部分实现。应用工厂、实例队列、独立删除和会话服务已有；主要业务仍集中 `app.py` | 跟随 UI 工作流拆分服务，优先统一事务、持久任务和图谱修订 |
| 发布工程 | 自动部署和健康检查已实现；工作流的 check 只检查凭据，没有测试关卡和自动回滚 | 引入测试先行、固定镜像版本、可回退发布及数据库迁移兼容检查 |

文档应特别修正：课程关联不等于已实现概念覆盖面板；全量 `graph.json` 仍有，但 `scope.json` 和 `neighbors.json` 已支持局部查询；“同名增量合并”不等于 AI 自动治理；现有快照回滚不等于完整版本历史。

## 建议实施顺序与验收

| 顺序 | 可独立交付的范围 | 验收 |
| --- | --- | --- |
| 1 | 共同布局、课程与讲次信息顺序；复核发布文案 | 390px 和 1440px 首屏可进入当前任务；设置不抢占主流程；未复核完成时没有误导性公开提示 |
| 2 | 批阅工作区、待复核定位、状态和保存操作 | 18 题夹具可连续复核，不丢输入；原页与对照区域可用；手机键盘不挡保存；报告状态独立显示 |
| 3 | 图谱浏览工作区、搜索和详情，提示词/AI 设置编辑 | 2,639 节点样本可搜索、下钻、返回；手机列表和抽屉可操作；连接摘要准确；长提示词不堆满页面 |
| 4 | 任务、事务与图谱版本底座 | 重复任务、删除后结果、过期预览、恢复切换与故障回退有可重现验证；发布有测试关卡 |
| 5 | 教师确认的根因诊断、复习与复测闭环 | 建议可追踪到题目/概念与教师确认；未考查概念不被直接宣称为薄弱点；复测效果可比较 |

每次只交付一个工作流，保留 Flask/Jinja2 与原生交互；先建立颜色、字体、间距、按钮、表格、状态、抽屉和确认对话框的共用规则，再抽取重复页面脚本。当前没有必要为了布局改造引入前端框架。
