# 学生手册

你在系统中可以：查看老师发布的讲次、上传手写作答的扫描件、查看批改结果与评语，以及查看考试成绩。

## 登录

- 账号由管理员创建；初始密码常见为 `123456`
- 若使用初始密码登录，系统会先要求修改密码，改完才能进入学习页
- 忘记密码请联系管理员重置

## 我的学习

登录后进入「我的学习」，分两块：

### 讲次批阅

讲次按课程分组，每门课一个可折叠的块：

- 可以同时展开多门课程；进入页面时默认只展开最近创建的一门课
- 折叠块标题右侧会显示该课程还有多少份作业未提交（全部提交后显示「全部已提交」）
- 课程内讲次按讲次名升序排列（如 `01_绪论`、`02_元素化学`）
- 老师上传了学生版讲义的讲次，可直接点「预览讲义」在页面内查看 PDF

每个讲次包含：

| 列 | 含义 |
|----|------|
| 讲次 | 标题、截止时间 |
| 状态 | 未提交 / 已提交 / 已批改 等 |
| 正确率 | 作业批改发布后显示（完全答对题数 ÷ 已判定题数），未发布显示「—」 |
| 讲义 | 有学生版 PDF 时可点「预览讲义」 |
| 操作 | 去提交 / 查看批改 / 查看进度 |

### 考试成绩

老师录入的考试成绩，显示考试名称、课程、日期、满分与你的得分、评语；分数还没录入时显示「未公布」。考试只公布分数与评语，不提供试卷批阅明细。

## 上传作业

进入讲次页，若老师上传了学生版讲义，页面顶部会显示「预览本讲学生版讲义（PDF）」，点击可在页面内预览。iPhone / iPad 上会直接用系统新标签页打开 PDF（可查看全部页面并双指缩放）；其他手机 / 平板上按页显示，用底部「上一页 / 下一页」翻页；也可以点预览面板右上角「新标签打开」用系统 PDF 阅读器查看全部页面。

提交作业分两步：

1. 点「选择图片 / PDF（可多选）」一次选多张，或点「拍照提交」直接调用手机相机；选中的文件进入**草稿箱**
2. 在草稿箱里预览缩略图、删除不满意的图片，确认无误后点「确认提交」才真正上传

规则：

- 支持格式：`png / jpg / jpeg / webp / pdf`，单文件不超过 20MB，一次最多 20 个文件
- 一次提交的多张图片属于同一份作业，老师会合并批阅；提交记录里会显示 `1/3`、`2/3` 等页码
- 可以多次提交，**老师以最新一次为准批改**
- 提交成功后页面显示「已提交」，等待老师批改

拍照建议：光线均匀、四角拍全、避免阴影；一页一张，多页直接多选后一起提交即可。

## 查看批改

老师完成批改并发布后，讲次页显示：

- **AI 汇总**：正确率，对 / 半对 / 错 / 无法判定 的题数
- **总评**：老师的文字评语（若有）
- **逐题明细**：每题题号、判定与简短说明

判定含义：

| 判定 | 含义 |
|------|------|
| 对 | 答案正确 |
| 半对 | 部分正确或关键步骤有缺失 |
| 错 | 答案错误 |
| 无法判定 | 书写不清或模型无法识别，需老师复核 |

> 老师复核完成前，批改结果不公开，页面会显示「老师批改中」。

## 修改密码

右上角点击自己的姓名进入改密页：输入旧密码与新密码（至少 6 位）后保存。

## 常见问题

| 现象 | 处理 |
|------|------|
| 上传失败 | 检查格式是否为 png/jpg/jpeg/webp/pdf、大小是否超过 20MB |
| 看不到批改 | 老师尚未发布；等状态变为「已批改」 |
| 正确率显示「—」 | 作业尚未批改发布，或该次批改还没有可判定的题目 |
| 考试成绩显示「未公布」 | 老师还没录入该场考试的分数 |
| 看不到某门课 | 你可能还没被加入该课程，联系老师 |
| 忘记密码 | 联系老师或管理员重置 |
