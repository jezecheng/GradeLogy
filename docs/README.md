# 文档索引与维护规则

## 当前操作说明（面向使用者）

| 文档 | 用途 | 数字助手 |
|---|---|---|
| [教师流程与前置条件](teacher-workflows.md) | 教师各流程的准入条件、主路径、分支和代码实现索引 | 教师助手优先检索 |
| [老师手册](teacher.md) | 教师功能细节、页面使用、异常处理 | 教师助手检索 |
| [学生手册](student.md) | 学生提交、公开结果、考试、薄弱点和错题本 | 学习助手检索 |
| [管理员手册](admin.md) | 账号、系统维护、备份恢复和日志 | 系统助手检索 |
| [知识图谱模块说明](knowledge_graph.md) | 图谱权限、建图机制、接口与实现边界 | 教师助手检索 |
| [新手上手指南](quick-start.md) | 文字流程与经筛选、不含学生身份/作答/成绩的界面示例 | 不作为助手检索源；Markdown 与教师流程表为可维护的当前说明 |

助手的角色文档清单在 `utilities/assistant.py:HELP_DOCS_BY_ROLE`。教师检索顺序是 `teacher-workflows.md`、`teacher.md`、`knowledge_graph.md`；学生和管理员分别只检索各自角色手册。`ask_help` 会附带回答约束及命中的当前手册章节。改动操作步骤时同步更新对应手册、助手检索和测试；不要让助手检索 README 摘要、历史维护记录或设计草案回答当前流程。

教师流程答案须明确区分「必须条件 / 可选或推荐 / 操作顺序 / 完成后的状态」，尤其不能混淆手动与自动批阅、生成报告与发布报告。当前权限开关 `TEMPORARY_GLOBAL_TEACHER_ACCESS` 默认为 `1`，课程/图谱范围见教师流程表与部署配置。

## 历史记录和方案

- `maintenance-progress.md`：截至 2026-11-18 的审计/维护快照，不代表当前行为。
- `ui-design.md`：2026-11-18 的教师界面方案，不是当前页面行为规范。
- `planning/` 与 `outputs/`：按各自日期保留的计划、评估和实施证据；状态应以记录日期和代码基线理解。
- `../deploy/README.md`：旧部署指南入口，仅用于提示迁移到当前部署文档。

## 冲突处理

1. 运行代码、权限校验和回归测试是实际行为依据；
2. `teacher-workflows.md` 是教师主流程、依赖关系和 prerequisites 的规范事实表，也是教师助手首选来源；
3. 角色手册解释页面操作与异常；
4. 有日期/代码基线的评估和规划材料仅作为历史证据，不覆盖当前实现。

每次影响业务流程的提交，应同步相关流程手册、角色手册、数字助手角色检索范围和检索回归测试。发布前至少验证教师常问的「手动批阅前置条件」「自动批阅未触发原因」「报告生成/发布条件」及学生端「待公布」含义。
