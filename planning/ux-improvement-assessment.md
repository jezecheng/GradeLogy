## UX 专家独立评审摘要

专门 UX 子代理独立阅读计划、相关手册与源码（未访问预生产、未修改文件），意见如下：

1. **调整优先级：** 先定会话服务端语义及考试历史映射；再做会话超时、考试状态和旧批阅范围失效；之后安排批量选课；学生截止列表与登录说明随后完成。
2. **UX-02 降级：** 当前已有逐题与报告独立状态和发布控制，不建议增加合并发布；做只读一致性审计即可。
3. **UX-04 加强：** 换答案/页码时防止旧范围继续用于批阅；标签生成目前由保存范围触发，需显式化 AI 副作用。
4. **交互验收补充：** 多标签/休眠后的会话状态、焦点/键盘/窄屏；选课逐项结果和不泄露停用账号；报告直接 URL 与撤回；截止边界和时区；答案更换后的范围失效；考试迁移重复运行、零分/仅评语/缺考分别测试。
5. **草稿提示：** 复核题目虽逐题自动保存，但总评在提交时才保存；不要承诺所有表单在登出前都可恢复。

## 建议的代码修改计划

1. **决策/设计（先于实现）：** 编写状态表，定逐题与报告维持独立发布；定考试待处理/缺考/已录入语义、旧记录和空分/仅评语映射；定 45 分钟空闲的服务端模型、用户活动请求和多标签/设备规则。
2. **会话可靠性（P1）：** 服务端权威 idle 时间、40 分钟提示与 45 分钟失效、显式续期接口及会话失效响应；测试轮询、标签页、休眠恢复、表单未保存提示。具体存储方案应在实施前结合当前单进程部署和恢复撤销机制评估。
3. **考试语义（P1）：** 明确状态与幂等迁移，改教师成绩表单/学生状态文案及统计；回归历史成绩可见性和本人数据边界。
4. **讲次范围可靠性（P1）：** 更换答案、重新选页、异步解析成功/失败时使旧范围失效或阻止批阅；将范围保存和 AI 标签操作的关系做成明确用户选择/状态。
5. **批量选课（P2）：** 多选搜索、确认预览、后端重新校验和逐项结果；使用隔离双学生/停用账号数据验证当前课程关系与权限。
6. **学生截止列表（P2）与登录帮助（P3）：** 保持课程成员隔离、显示时区与状态规则；登录说明公开可访问并保证键盘/窄屏体验。
7. **复核发布（持续验收）：** 维持逐题结果、报告独立发布；仅在状态呈现上消除歧义，不默认合并。

## 阶段 0 决策记录（本轮按计划推荐值实施）

1. **逐题结果与报告：** 保持独立状态、独立发布和独立撤回；本轮不做合并发布入口。
2. **考试：** 保存即对学生可见，不新增草稿/发布步骤；状态采用“待录入 / 缺考 / 已录入”。缺考必须由教师明确标记，不作为零分统计。
3. **历史考试映射：** 已有成绩或评语记录映射为“已录入”（含零分和仅评语，维持现有可见性）；没有记录或空记录映射为“待录入”；绝不推断缺考。迁移需幂等。
4. **会话：** 连续无有效用户活动 45 分钟到期，40 分钟提醒；验证通过的页面导航、已通过 CSRF 的写操作和显式用户输入心跳算活动。静态资源、健康检查及后台 JSON 轮询不续期。同浏览器标签共享活动/登出；独立浏览器登录视为独立会话。服务端记录为最终依据。
5. **未保存内容：** 不保证自动提交/恢复通用表单；提醒明确告知保存内容，现有逐题自动保存行为不变。
6. **近期截止定义：** “未来 7 天”按连续 7×24 小时计算；逾期区只含完全没有提交记录的任务。已提交任务从逾期区移出，按最新提交状态保留在课程列表；无截止时间只留在课程列表。
