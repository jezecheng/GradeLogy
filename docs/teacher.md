# 老师手册

老师负责课程、学生名单、作业与批改。所有功能都在登录后的导航栏入口。

## 登录与改密

- 账号由管理员创建；初始密码为 `123456` 时，首次登录必须先改密
- 右上角姓名可进入改密页

## 课程与学生名单

### 创建课程

「我的课程」→ 填写课程名称与简介 → 创建。课程卡片显示学生数与作业数。

### 添加学生

进入课程页，两种方式：

1. **单个加入**：从「学生账号」下拉中选择（列表只显示管理员已创建、且尚未加入本课程的学生）
2. **CSV 批量导入**：展开「批量导入学生名单（CSV）」，上传后先进入预览页，确认后才写入

CSV 格式（每行一条，首行表头可选）：

```
用户名,姓名,真实姓名,学籍号,初始密码
stu001,小张,张三,20260001
stu002,小李,李四,20260002,abc123
```

导入规则：

- 上传后先预览：逐行列出「新建账号 / 加入课程 / 已在课程 / 无法处理」，**确认前不会写库**
- 用户名已存在 → 直接加入课程，不重复建号
- 用户名不存在 → 自动创建学生账号并加入课程
- 「姓名」为显示名；「真实姓名」可留空（默认与姓名相同）；「学籍号」用于区分同名或导入教务系统，可在表头为「学号」时自动识别
- 未填密码时使用 `123456`，该账号首次登录强制改密；填写自定义密码则不强制
- 校验用户名（2-32 位字母、数字或 `_.-`）、密码长度（≥6）、文件内重复、同名非学生账号
- 支持 UTF-8（含 Excel 的 BOM）与 GBK；Excel 请另存为「CSV UTF-8」
- 单次最多 1000 行、文件 ≤1MB；错误行在预览页完整列出，确认后汇总提示
- 预览内容暂存 1 小时，超时需重新上传

移出学生不会删除账号，只解除该课程的选课关系。

### 批量建课并导入学生

「我的课程」→ 展开「批量建课并导入学生（CSV）」，每行「课程,用户名,姓名[,初始密码]」：

```
课程,用户名,姓名,学籍号
高二（1）班,stu001,张三,20260001
高二（1）班,stu002,李四,20260002
高二（2）班,stu003,王五,20260003
```

- 课程按名称匹配：当前老师名下不存在则自动创建，已存在则复用
- 学生规则与单个课程导入相同；同一文件内可一次创建多门课程
- 同样先预览（汇总新课程数、学生动作），确认后才写库
- 单次最多 2000 行、文件 ≤1MB；预览暂存 1 小时

## 作业与标准答案

### 发布作业

课程页「作业」卡片：填写标题、说明、截止时间，可同时上传教师版标准答案 PDF（也可稍后上传）。

### 上传 / 更换答案

作业详情页「标准答案」卡片支持上传或更换答案 PDF。AI 批改以该 PDF 为参考。

### 批阅方式（整份原卷，不切题）

作业详情页不需要「提取标准答案」或设置范围。点提交卡片上的「AI 批阅」时，系统会把两份材料一起交给模型：

1. 学生提交的作业（PDF 或扫描图片）
2. 作业的教师版标准答案 PDF

系统把两份文件的每一页渲染成图片后一次性发送，模型看到完整原卷，逐题输出题号、学生作答 OCR、标准答案要点、判定、建议分数与评语，不做任何题目裁剪。需要「AI 设置」里选择**支持图片输入**的多模态模型，输出上限建议 ≥32k。

单份批阅实测：约 26 页图片、45 题，DeepSeek 视觉版约 90 秒、4.5 万 token；模型卡死时 5 分钟超时后直接报错，不会反复重试。

## AI 设置

导航栏「AI 设置」：

| 项 | 说明 |
|----|------|
| 接口地址 | 任意 OpenAI 兼容服务，如 `https://tokenhub.tencentmaas.com/v1` |
| API Key | 留空提交表示保持原值不变 |
| 模型 | 必须是**支持图片输入的多模态模型**，如 `deepseek-v4-flash-vision-exp`、`qwen-vl-max`、`gpt-4o` |
| 演示模式 | 未配 Key 时可用，生成占位批阅结果，仅用于走通流程 |
| 测试连接 | 发送一次最小请求验证地址、Key 与模型 |

服务端若通过环境变量注入了 `AI_API_URL / AI_API_KEY / AI_MODEL`，会优先于页面配置。

## AI 批改与人工复核

### 开始批改

作业详情页的提交列表，每份提交有两个入口：

- **AI 批阅 / 重新批阅**：把学生作业与标准答案整份交给模型，一次返回逐题结果
- **逐题核对**：打开发布前的复核页

### 复核页

两栏同屏：

| 左 | 右 |
|----|----|
| 可编辑的 OCR 文本框、判定、得分、评语 | 该题标准答案（可修正） |

- 每题有判定下拉：对 / 半对 / 错 / 无法判定；可修改得分与评语
- 页面底部填写总分与总评
- 点击保存后，提交状态变为「已批改」，学生端立即可见；**保存即发布**
- 页面右上角「查看原始扫描件」可并排打开学生原卷 PDF 核对

### 快速手动更正

提交卡片里的「手动更正批改」可直接改总分与总评，不改逐题记录，同样会把状态置为「已批改」。

## 教案

课程页「教案」卡片：新建、编辑、删除。教案内容为纯文本，按课程归属。

## 常见问题

| 现象 | 处理 |
|------|------|
| 批改全部失败 | 检查 AI 设置与额度；日志中看 `HTTP 402` / `429` / `请求失败` |
| 提示模型不支持图片 | 换用支持图片输入的多模态模型；纯文本模型无法读取扫描件 |
| 批阅超时（5 分钟） | 模型卡住或题量过大；换更快的视觉模型，或压缩 PDF 页数后重试 |
| 输出被截断 | 模型输出上限太小或题量过多；调大输出上限或减少一次批阅的页数 |
| 题目漏判 | 模型未返回的题不会凭空补；可在复核页手动补充，或重试批阅 |
| 批改很慢 | 整份 PDF 一次请求，页数越多越慢；可压缩 PDF 后重试 |
| 学生看不到成绩 | 确认已保存复核页（状态应为「已批改」） |
