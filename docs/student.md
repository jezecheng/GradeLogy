# 学生手册

你在系统中可以：查看老师发布的讲次、上传手写作答的扫描件、查看批改结果与评语，以及查看考试成绩。

管理员恢复备份后，请用恢复后的账号重新登录。
移出课程后，该课程的学习记录和薄弱点不再保留；其他课程不受影响。

## 快速上手：第一次交作业

1. **登录改密**：用管理员或老师给你的账号登录；初始密码 `123456` 时会先要求改密（见「登录」）
2. **看有哪些作业**：「我的学习」里按课程分组列出所有讲次，课程折叠块标题右侧显示还有几份没交（见「我的学习」）
3. **读讲义**：讲次有学生版讲义时，点「预览讲义」看原卷（见「上传作业」）
4. **交作业**：进入讲次页 →「选择图片 / PDF（可多选）」或「拍照提交」→ 在草稿箱里检查 →「确认提交」
5. **等老师发布**：人工复核完成后可能显示「待公布」；老师在报告页发布后状态变为「已批改」，再点「查看批改」看正确率、报告和逐题明细（见「查看批改」）
6. **看考试分数**：「我的学习」下半部分的「考试成绩」
7. **复习薄弱点**：批改发布后，从「我的学习」顶部进入「我的薄弱点图谱」，标记状态或移除（见「我的薄弱点图谱」）

遇到问题先看文末「常见问题」；忘记密码只能联系老师或管理员重置。

## 登录

- 账号由管理员创建；初始密码常见为 `123456`
- 若使用初始密码登录，系统会先要求修改密码，改完才能进入学习页
- 连续 40 分钟无操作会显示提醒，45 分钟无操作后自动退出。未提交的内容不会自动提交
- 忘记密码请联系管理员重置

## 我的学习

登录后进入「我的学习」，主区是「讲次批阅」，页面下方是「考试成绩」（见下一节）。

**讲次批阅**：讲次按课程分组，每门课一个可折叠的块：

页面顶部另有「近期截止与逾期」：显示未来 7 天内的截止任务，以及仍未提交的逾期任务，按截止时间排序；已提交任务显示最新提交状态。时间按你设置的显示时区展示。无截止时间的讲次不会进入该区块，但仍保留在下方课程列表中。

- 可以同时展开多门课程；进入页面时默认只展开最近创建的一门课
- 折叠块标题右侧会显示该课程还有多少份作业未提交（全部提交后显示「全部已提交」）
- 课程内讲次按讲次名升序排列（如 `01_绪论`、`02_元素化学`）
- 老师上传了学生版讲义的讲次，可直接点「预览讲义」在页面内查看 PDF

每个讲次包含：

| 列 | 含义 |
|----|------|
| 讲次 | 标题、截止时间 |
| 状态 | 未提交 / 已提交 / 待公布 / 已批改 等 |
| 正确率 | 作业批改发布后显示（完全答对的独立批改项 ÷ 独立批改项总数；无法判定也计入分母），未发布显示「—」 |
| 讲义 | 有学生版 PDF 时可点「预览讲义」 |
| 操作 | 去提交 / 查看批改 / 查看进度 |

## 查看考试成绩（分数与评语）

考试列表会显示考试名称、课程、日期、满分、状态、得分与评语。状态为「待录入」表示老师尚未处理；「缺考」是老师明确标记的状态，不等同于零分；「已录入」的分数或评语保存后立即可见，0 分也会正常显示。考试只记录分数与评语，不提供试卷批阅明细。

## 上传作业（交作业、拍照或选 PDF）

进入讲次页，若老师上传了学生版讲义，页面顶部会显示「预览本讲学生版讲义（PDF）」，点击可在页面内预览。iPhone / iPad 上会直接用系统新标签页打开 PDF（可查看全部页面并双指缩放）；其他手机 / 平板上按页显示，用底部「上一页 / 下一页」翻页；也可以点预览面板右上角「新标签打开」用系统 PDF 阅读器查看全部页面。

提交作业分两步：

1. 点「选择图片 / PDF（可多选）」一次选多张，或点「拍照提交」直接调用手机相机；选中的文件进入**草稿箱**
2. 在草稿箱里预览缩略图、删除不满意的图片，确认无误后点「确认提交」才真正上传

规则：

- 支持格式：`png / jpg / jpeg / webp / pdf`，单文件不超过 20MB，一次最多 20 个文件
- 一次提交的多张图片属于同一份作业，老师会合并批阅；提交记录里会显示 `1/3`、`2/3` 等页码
- 可以多次提交，**老师以最新一次为准批改**
- 提交成功后页面显示「已提交」，等待老师批改

拍照建议：光线均匀、四角拍全、避免阴影；一页一张，多页直接多选后一起提交即可。

## 查看批改（正确率、评阅报告与逐题明细）

老师人工复核完成后，只有在报告页点「一键发布给学生」时，报告与逐题结果才会同时公开。复核完成但尚未发布时，讲次状态显示「待公布」，不能查看批改内容。

老师重新批阅时，旧结果会暂时隐藏；新结果需要重新复核、生成报告并发布。老师保存草稿或撤回发布后，报告与逐题结果均不可见。

- **AI 汇总**：正确率，对 / 半对 / 错 / 无法判定 的题数
- **评阅报告**：逐题明细、失分归因和评价（若有）
- **逐题明细**：每题题号、判定与简短说明

判定含义：

| 判定 | 含义 |
|------|------|
| 对 | 答案正确 |
| 半对 | 部分正确或关键步骤有缺失 |
| 错 | 答案错误 |
| 无法判定 | 书写不清或模型无法识别，需老师复核 |

> 是否公开以老师发布状态为准。「待公布」表示老师已完成复核，但还没有发布报告与逐题结果。

## 我的薄弱点图谱（状态、移除与自动回退）

批改发布后，系统会把每道题关联的知识点标签汇总成你的个人薄弱点。入口在「我的学习」页顶部的「🔗 我的薄弱点图谱」，批改报告顶部也有链接。

页面从上到下依次是：

| 区域 | 作用 |
|------|------|
| 薄弱点星图 | 只点亮与你薄弱点相关的知识点；点击亮点可定位到下方对应卡片 |
| 筛选按钮 | 全部 / 待复习 / 已复习 / 已掌握，只影响当前页面的显示 |
| 课程分组 | 每门课一个可折叠块，卡片按薄弱程度排序 |
| 薄弱点卡片 | 累计判定（对 / 半对 / 错 / 共几题）、合并的标签、前置知识、相关错题入口 |

### 三种复习状态

| 状态 | 含义 |
|------|------|
| 薄弱 | 默认状态，仍需要复习 |
| 已复习 | 已经复习过，暂时不需要提醒 |
| 已掌握 | 已经掌握 |

在卡片底部选择状态、可填写备注，点「保存」生效。状态和备注只属于你个人，老师看不到。

### 移除按钮

卡片右上角有「移除」按钮：

1. 点击后浏览器弹出确认框「确定移除这个薄弱点？后续讲次再做错会自动恢复。」
2. 确认后卡片立即从列表消失，星图也不再点亮该知识点，页面顶部提示「已移除该薄弱点」
3. 移除只是把它从待复习列表里拿掉，**不会删除批改记录**，「错题本」里的对应错题仍然保留

不需要手动找回：后续讲次再次做错时会自动回到「薄弱」。

### 状态何时会自动回退

老师对同一份作业反复批改（修正判定、补充评语等）时：

- 你的「已复习 / 已掌握」状态与备注**会保留**，不会因为重批被打回「薄弱」
- 同一个知识点不会重复生成卡片，判定统计按最新一次结果刷新

只有**新的讲次**出现下列情况时才自动回退：

| 情况 | 结果 |
|------|------|
| 新讲次该知识点被判「错」或「半对」 | 状态自动回到「薄弱」，重新出现在待复习列表与星图 |
| 之前已移除，新讲次又做错 | 自动恢复为「薄弱」 |
| 新讲次全部答对 | 保持你当前设置的状态不变 |

> 判定以每个讲次最近一次提交为准；同一讲重复提交不会重复累计题数。

## 修改密码

右上角点击自己的姓名进入改密页：输入旧密码与新密码（至少 6 位）后保存。

## 数字助手（右下角学习助手）

页面右下角的蓝色圆形按钮就是「学习助手」。第一次登录会出现一个提示气泡指向它，点气泡或按钮即可打开。

可以直接用日常说法提问：

- 「我还有什么作业没交？」——按截止时间列出未提交的讲次
- 「这次作业的批改结果怎么样？」——公开状态、正确率、报告与逐题明细
- 「我期中考试多少分？」——考试成绩与老师评语
- 「怎么交作业 / 怎么看批改？」——查使用说明并给出步骤

注意事项：

- 助手是**只读**的，只能看到你自己的数据，不能改分数、不能替你交作业
- 批改结果以老师发布为准；助手说「尚未发布」就是老师还没公开
- 助手需要 AI 接口，由老师或管理员配置，没配置时会提示「还没有配置 AI 接口」

## 常见问题（上传失败、看不到批改、忘记密码）

| 现象 | 处理 |
|------|------|
| 上传失败 | 检查格式是否为 png/jpg/jpeg/webp/pdf、大小是否超过 20MB |
| 看不到批改 | 若状态为「待公布」，老师尚未发布；等老师发布后状态变为「已批改」 |
| 正确率显示「—」 | 作业尚未批改发布，或该次批改还没有可判定的题目 |
| 考试成绩显示「未公布」 | 老师还没录入该场考试的分数 |
| 看不到某门课 | 你可能还没被加入该课程，联系老师 |
| 忘记密码 | 联系老师或管理员重置 |
