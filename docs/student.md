# 学生手册

你在系统中可以：查看老师发布的讲次、上传手写作答的扫描件、查看批改结果与评语，以及查看考试成绩。

## 登录

- 账号由老师或管理员创建；初始密码常见为 `123456`
- 若使用初始密码登录，系统会先要求修改密码，改完才能进入学习页
- 忘记密码请联系老师或管理员重置

## 我的学习

登录后进入「我的学习」，分两块：

### 讲次批阅

你所在课程的每一个讲次一条记录：

| 列 | 含义 |
|----|------|
| 讲次 | 标题、所属课程、截止时间 |
| 状态 | 未提交 / 已提交 / 已批改 等 |
| 得分 | 老师发布成绩后显示，未发布显示「—」 |
| 操作 | 去提交 / 查看批改 / 查看进度 |

### 考试成绩

老师录入的考试成绩，显示考试名称、课程、日期、满分与你的得分、评语；分数还没录入时显示「未公布」。考试只公布分数与评语，不提供试卷批阅明细。

## 上传作业

进入讲次页，若老师上传了学生版讲义，页面顶部会显示「下载本讲学生版讲义（PDF）」。在「上传作业扫描件」选择文件：

- 支持格式：`png / jpg / jpeg / webp / pdf`，单文件不超过 20MB
- 可以多次提交，**老师以最新一次为准批改**
- 提交成功后页面显示「已提交」，等待老师批改

拍照建议：光线均匀、四角拍全、避免阴影；多页请合成一个 PDF，或按页分别提交（以最后一次为准，注意不要漏页）。

## 查看批改

老师完成批改并发布后，讲次页显示：

- **AI 汇总**：总分、对 / 半对 / 错 / 无法判定 的题数
- **总评**：老师的文字评语（若有）
- **逐题明细**：每题题号、判定、得分与简短说明

判定含义：

| 判定 | 含义 |
|------|------|
| 对 | 答案正确 |
| 半对 | 部分正确或关键步骤有缺失 |
| 错 | 答案错误 |
| 无法判定 | 书写不清或模型无法识别，需老师复核 |

> 老师复核完成前，批改结果不公开，页面会显示「老师批改中」。

## 修改密码

右上角点击自己的姓名进入改密页：输入旧密码与新密码（至少 6 位）后保存。

## 常见问题

| 现象 | 处理 |
|------|------|
| 上传失败 | 检查格式是否为 png/jpg/jpeg/webp/pdf、大小是否超过 20MB |
| 看不到批改 | 老师尚未发布；等状态变为「已批改」 |
| 得分显示「—」 | 成绩未发布，或该题老师未给分值 |
| 考试成绩显示「未公布」 | 老师还没录入该场考试的分数 |
| 看不到某门课 | 你可能还没被加入该课程，联系老师 |
| 忘记密码 | 联系老师或管理员重置 |
